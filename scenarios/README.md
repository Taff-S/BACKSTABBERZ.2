# Encounter scenarios

Run any `.bat` file in this directory to start that scenario. The first two
player prompts are answered automatically; later prompts are entered in the
same console and labeled by player number.

Every scenario starts with the same setup:

- Player 1: full health, 100 coins, Executioner's Sword
- Player 2: half health, 1000 coins, Practice Sword

Available launchers cover the implemented encounters, the vampire shop
placeholder, the rest room, and a standard-slime combat. Maven and a JDK
matching the project compiler release are required.
